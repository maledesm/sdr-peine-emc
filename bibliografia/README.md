# Papers

PDF de la bibliografía del proyecto. La lista comentada está en [`docs/bibliografia.md`](../docs/bibliografia.md).

El repositorio es privado: los papers con copyright no deben pasar a una copia pública.

Nombre de cada archivo: año, primer apellido (sin acentos) y el título o sus palabras clave, cada palabra con mayúscula y separadas por `_`: `AAAA_Apellido_Palabras_Clave.pdf`, por ejemplo `2007_Mullner_Conducted_Radiated_Comb_Generator_Techniques.pdf`. Las siglas van como se escriben (SDR, EMC, GaAs). Las tesis llevan `_Tesis` al final, los borradores `_Borrador` y los que son solo un resumen `_Resumen`.
